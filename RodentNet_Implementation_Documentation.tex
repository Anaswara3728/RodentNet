\section{Security Layer}
\label{sec:security}

\subsection{Shamir-Backed Key Custody for ML-DSA-65}
Each hospital requires a cryptographic identity to sign model updates. True threshold Dilithium (where signing is distributed via MPC) is currently computationally prohibitive. Therefore, RodentNet implements \emph{Shamir-Backed Key Custody}: the central authority generates the ML-DSA-65 private key, splits it into Shamir shares, distributes the shares to the hospital admins, and destroys the key in memory. The hospital reconstructs the key locally strictly for signing. 

The codebase integrates genuine NIST ML-DSA-65 signatures using the \lstinline|dilithium-py| package (standard Dilithium3 parameter set, FIPS 204 compliant, producing authentic 3{,}293-byte signatures).

\subsection{Secure Multi-Party Computation --- Authenticated Post-Quantum Masking}
To prevent the central server from inspecting local clinical model weights, \lstinline|crypto/mpc.py| implements pairwise additive masking. 

Crucially, deriving masks from public client IDs offers zero cryptographic privacy against an honest-but-curious aggregator. RodentNet implements an \textbf{Authenticated Post-Quantum Key Exchange} protocol combining \textbf{ML-KEM-768 (Kyber768)} for key encapsulation and \textbf{ML-DSA-65 (Dilithium3)} for mutual identity authentication:

\begin{enumerate}[itemsep=2pt]
  \item \textbf{Ephemeral Keypair Generation:} Each hospital client $i$ generates an ephemeral Kyber-768 keypair $(pk_{K, i}, sk_{K, i})$ and signs $pk_{K, i}$ using its long-term Dilithium3 private key: $\sigma_i = \text{Sign}(sk_{D, i}, pk_{K, i})$.
  \item \textbf{Mutual Authentication:} Clients exchange public keys. Peer $j$ verifies $\sigma_i$ against client $i$'s registered Dilithium public key before key encapsulation, preventing active man-in-the-middle attacks.
  \item \textbf{Post-Quantum Encapsulation:} For each client pair $(i, j)$ with $i < j$, client $i$ executes $\text{Encaps}(pk_{K, j}) \to (ss_{ij}, ct_{ij})$ and transmits $ct_{ij}$ to client $j$. Client $j$ decapsulates $\text{Decaps}(sk_{K, j}, ct_{ij}) \to ss_{ij}$.
  \item \textbf{Pairwise Masking:} The shared 32-byte secret $ss_{ij}$ seeds SHAKE-256 to generate deterministic weight masks:
  \[
  \text{mask}_{ij} = \text{SHAKE-256}(ss_{ij} \parallel \text{round\_id} \parallel \text{layer\_index}) \pmod{p}
  \]
  \item \textbf{Cancellation on Aggregator:} Client $i$ adds the mask; Client $j$ subtracts the mask. Summing across verified clients yields exact mask cancellation while revealing zero information about individual client weights.
  \item \textbf{Finite Field Selection:} Aggregation operates over the 40-bit prime field $p = 1{,}099{,}511{,}627{,}689$ ($2^{40}-87$), which prevents integer overflow for up to 100 hospital clients while preserving full floating-point precision upon decoding.
\end{enumerate}

\textbf{Session Key Amortization Design:} Pairwise ML-KEM shared secrets and Shamir secret shares are established once during initial session setup (Round 0) and persist across all training rounds. In each subsequent federated round, clients derive fresh pairwise additive masks using SHAKE-256 keyed on \lstinline|(shared_secret || round_id || layer_name)|, incurring zero KEM encapsulation or key-exchange overhead during model training. Bandwidths are reported in binary mebibytes ($1\,\text{MiB} = 2^{20}\,\text{bytes} = 1{,}048{,}576\,\text{bytes}$) alongside decimal megabytes.

\noindent\textbf{Demonstrated Forward-Secrecy and Active MITM Defense:} Forward secrecy across communication rounds is achieved by distributing Shamir shares over per-round derived seeds $K_{i,j}^{(r)} = \text{SHAKE-256}(s_{i,j} \parallel r)$ rather than the master session secret. If a hospital node drops offline in Round $r$, the server reconstructs only $K_{i,j}^{(r)}$ to cancel stranded masks; because SHAKE-256 is preimage-resistant, past updates ($r' < r$) remain uninvertible. Automated unit tests in \lstinline|tests/test_forward_secrecy_and_mitm.py| formally verify both properties:
\begin{enumerate}[itemsep=1pt]
  \item \textbf{Active MITM Defense:} Substituted ML-KEM ciphertexts fail ML-DSA-65 signature verification over $(c \parallel pk \parallel \text{session})$, preventing ciphertext replacement.
  \item \textbf{Forward Secrecy:} Attempted unmasking of Round 1 updates using reconstructed Round 2 keys yields pseudorandom error exceeding $1{,}000\times$ update magnitude.
\end{enumerate}

\subsection{Server Aggregation (\lstinline|strategy.py|)}
\begin{enumerate}[itemsep=2pt]
  \item Verify each client's signature against the \lstinline|ThresholdRegistry|; drop any failed/replayed submission.
  \item Sum the quantized, masked weights of verified clients --- masks cancel exactly (provided all clients submit).
  \item Divide by (quantization scale $\times$ sample count) $\to$ true global average.
\end{enumerate}

\section{Data Pipeline --- VDJdb}
\label{sec:data}

\textbf{Implemented preprocessing steps} (\lstinline|vdjdb_data.py|):
\begin{itemize}[itemsep=2pt]
  \item \textbf{Strict Leakage-Free Splitting:} Because VDJdb contains heavy TCR duplication, standard random splits cause severe data leakage (the model memorizes TCRs seen in training). RodentNet strictly groups by \lstinline|CDR3| sequence, ensuring that the test set evaluates \emph{unseen} TCR generalization.
  \item \textbf{Confidence filtering:} rows with \lstinline|vdjdb.score < 1| discarded.
  \item \textbf{Episodic sampling:} custom \lstinline|EpisodicBatchSampler| forces rare and common epitopes into every batch equally.
\end{itemize}

\subsection{Threat Model and Security Argument}
RodentNet explicitly defines and defends against the following standard adversarial models:
\begin{itemize}[itemsep=2pt]
  \item \textbf{Honest-but-Curious Server:} The aggregation server follows the training protocol faithfully but attempts to inspect or infer private patient biological representations from received model updates.
  \item \textbf{Active Server / Man-in-the-Middle:} An active adversary attempting to inject malicious key exchange parameters to decrypt pairwise updates. This attack is blocked because clients authenticate their ephemeral Kyber public keys with long-term Dilithium signatures.
  \item \textbf{Post-Quantum Adversary:} An adversary capable of recording network transcripts today and deploying Shor's algorithm on future quantum hardware (``Harvest Now, Decrypt Later''). Both Dilithium (ML-DSA-65) and Kyber (ML-KEM-768) provide lattice-based security against quantum polynomial-time attacks.
  \item \textbf{Client Dropout:} Hospital clients experiencing network failures during local training or transmission. Pairwise seeds are split among cohorts via $T$-of-$N$ Shamir Secret Sharing, allowing the server to reconstruct stranded masks for disconnected clients and preserve aggregate correctness.
\end{itemize}

\subsection{Empirical Attack and Defense Validation}
To verify the privacy claims empirically, we implemented dedicated automated attack tests (\lstinline|tests/test_privacy_attack_demo.py|):
\begin{enumerate}[itemsep=2pt]
  \item \textbf{Naive Public Seed Attack:} In an unauthenticated system where masks derive from public IDs, the server recomputes the exact masks and recovers raw client weights with zero error.
  \item \textbf{Authenticated ML-KEM Defense:} Under our protocol, the server lacks the Kyber private keys. Attempting to strip public masks yields only pseudorandom noise ($R^2 \approx 0$), proving that updates remain confidential.
  \item \textbf{Active Key Substitution Defense:} If a server intercepts and substitutes an evil Kyber public key, Dilithium signature verification fails, causing the client to immediately terminate the handshake.
  \item \textbf{Shamir Dropout Recovery:} If a hospital node drops out mid-round, surviving nodes reveal their Shamir shares of its pairwise seeds, allowing the server to cancel stranded masks without unmasking surviving nodes.
\end{enumerate}

\begin{itemize}[itemsep=2pt]

\textbf{Measured Scientific Findings:}
\begin{enumerate}[itemsep=2pt]
  \item \textbf{Performance of Simple Sequence Heuristics:} 1-NN Levenshtein distance achieves $54.27 \pm 3.34\%$ balanced accuracy ($60.77\%$ raw accuracy), and 3-mer logistic regression achieves $43.09 \pm 4.78\%$ balanced accuracy ($60.25\%$ raw accuracy, $0.8326$ AUROC). These simple sequence baselines outperform neural models trained from scratch on balanced accuracy. This is expected given public human TCR sequence homology. The core contribution of this work is not claiming a superior classifier trained from scratch on small biological samples, but demonstrating a \textbf{post-quantum authenticated, dropout-tolerant federated aggregation framework} that preserves model utility and protects genomic privacy.
  \item \textbf{Empirical Federated Collaboration Gain:} An isolated hospital training on its own skewed cohort (Mean across all 3 hospitals) achieves only $33.86 \pm 3.56\%$ balanced accuracy and $0.7550$ Macro AUROC. Multi-hospital federated collaboration via Secured FedAvg achieves $38.70 \pm 4.49\%$ balanced accuracy (+4.84 pp absolute gain; Plain FedAvg: +5.18 pp) and $0.8162$ Macro AUROC (+0.0612 gain), demonstrating consistent collaboration benefit across all 5 seeds.
  \item \textbf{Resolution of Local Collapse Signature:} Isolated hospital models exhibit raw accuracy equal to the majority class share ($46.09\%$) but low balanced accuracy ($33.86\%$), reflecting non-IID collapse toward local dominant epitopes. Federated aggregation overcomes this collapse.
  \item \textbf{FedAvg vs. FedPer Generalization:} On both local-matched test sets ($37.91\%$ vs $35.61\%$) and the global test set ($39.04\%$ vs $33.03\%$), global consensus FedAvg outperforms FedPer. In small-sample immunological modeling, sharing the complete parameter state provides superior regularization compared to private classification heads.
  \item \textbf{Label-Shuffle Negative Control:} Under randomized label shuffling, balanced accuracy drops to $10.00 \pm 0.00\%$ and AUROC to $0.5049 \pm 0.0313$ (exact chance), confirming that the evaluation pipeline does not reflect indexing artifacts.
\end{enumerate}

\end{enumerate}
